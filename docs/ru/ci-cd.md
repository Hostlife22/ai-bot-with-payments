# Автоматизация GitHub

## Проверки и обновления

`ci.yml` проверяет форматирование, ссылки документации, TypeScript, ESLint, модульные тесты и сборку на Node.js 22, 24 и 26. Отдельная задача запускает интеграционные тесты с PostgreSQL 15 и Redis 7. `codeql.yml` анализирует JavaScript/TypeScript при push, pull request и еженедельно.

Dependabot проверяет npm, GitHub Actions и базовые Docker-образы каждое воскресенье. Минорные обновления и исправления объединяются; мажорные версии идут отдельными PR. Автоматического слияния нет. Типы Node.js остаются на версии 22 до изменения минимальной поддерживаемой версии.

## Документация, архив и GitHub Pages

`docs.yml` проверяет Markdown, собирает трёхъязычный сайт VitePress, проверяет навигацию, поиск, диаграммы и мобильное меню в Chromium. Архив `documentation.tar.gz` доступен в разделе **Artifacts** запуска workflow.

Один раз выберите **Settings → Pages → Build and deployment → Source → GitHub Actions**. Успешные push в основную ветку, теги версий и ручные запуски основной ветки публикуют сайт. Pull request только собирает и проверяет документацию. Ожидаемый адрес: <https://hostlife22.github.io/ai-bot-with-payments/>. Сначала необходимо отправить файлы в GitHub и включить Pages.

```bash
npm ci
npm run docs:check
npm run docs:build
npm run docs:preview
npx playwright install chromium
npm run docs:test
```

Для проверки префикса проекта задайте `DOCS_BASE=/ai-bot-with-payments/` при сборке и тестировании. Исходники остаются в `docs/eng`, `docs/ru`, `docs/zh`; `.docs-site/` генерируется и игнорируется Git. Используется стандартная адаптивная тема VitePress с локальным поиском.

## Docker и релизы

`docker.yml` собирает и проверяет рабочий образ для веток и PR. Теги версий публикуют AMD64/ARM64-образы в GHCR с SBOM и provenance. Для ручной публикации нужно выбрать `publish`; по умолчанию он выключен. Используется `GITHUB_TOKEN` workflow.

`release.yml` запускает проверки с PostgreSQL и Redis, создаёт архив исходников и скомпилированного приложения, CycloneDX SBOM рабочих зависимостей и `SHA256SUMS`. Установленные зависимости, настоящие `.env` и дампы базы исключены. После распаковки выполните `npm ci --omit=dev`.

Тег должен совпадать с версией `package.json`, например `v1.0.0`. Запуск по тегу создаёт **черновик** релиза; ручной запуск сохраняет только артефакты кандидата. Опубликованный релиз не перезаписывается. Локально: `npm run build && npm run release:prepare`.

CodeQL требует доступности code scanning для репозитория. Pages и публикация пакетов зависят от разрешений организации и репозитория. Добавление файлов само по себе ничего не публикует.
