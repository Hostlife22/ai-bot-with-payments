# Сторонние компоненты

[English](../eng/third-party-notices.md) · **Русский** · [简体中文](../zh/third-party-notices.md)

Полный список пакетов и исходные тексты LICENSE/NOTICE находятся в [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md). Тексты лицензий сохраняются на языке правообладателей; локализация документации их не заменяет.

## Обновление

```sh
npm install
npm run docs:notices
```

Генератор использует установленное транзитивное runtime-дерево и прямые инструменты разработки, читает метаданные и доступные файлы лицензий без сетевого поиска. Результат содержит точные версии, заявленные лицензии, платформу установки и SHA-256 lockfile. Одинаковые тексты объединяются с указанием всех исходных пакетов.

Некоторые опубликованные пакеты не содержат файла лицензии или NOTICE. Они перечисляются отдельно: метаданные не подменяются придуманными копирайтами и текстами других версий. Перед распространением проверьте исходный релиз таких пакетов.

Опциональные нативные зависимости отличаются между платформами. Перегенерируйте уведомления в отдельном окружении целевой поставки. Транзитивные инструменты разработки не входят в охват этого перечня.

## Лицензия проекта

Код проекта использует [MIT](../../LICENSE). Сторонние библиотеки сохраняют свои условия. Фотографии и ответы внешних API требуют отдельной оценки прав использования. При обновлении зависимости включайте изменения манифеста и уведомлений в один PR; локальный lockfile не коммитится.
