## Переменные окружения

| Переменная            | Обязательность | Значение                                                                                                |
| --------------------- | -------------- | ------------------------------------------------------------------------------------------------------- |
| `BOT_TOKEN`           | Всегда         | Токен отдельного Telegram-бота. Проверяется наличие значения; доступ к Telegram проверяется при старте. |
| `ADMIN_ID`            | Всегда         | Положительный целый Telegram ID, представимый безопасным целым JavaScript.                              |
| `OPENROUTER_API_KEY`  | Всегда         | Ключ OpenRouter для текстовых и графических запросов.                                                   |
| `DATABASE_URL`        | Всегда         | URL с протоколом `postgres:` или `postgresql:`.                                                         |
| `REDIS_URL`           | Всегда         | URL с протоколом `redis:` или `rediss:`.                                                                |
| `POSTGRES_USER`       | Для Compose    | Пользователь PostgreSQL; значение по умолчанию — `db_user`.                                             |
| `POSTGRES_PASSWORD`   | Для Compose    | Пароль PostgreSQL. Согласуйте его с `DATABASE_URL`.                                                     |
| `POSTGRES_DB`         | Для Compose    | Имя БД; значение по умолчанию — `db_name`.                                                              |
| `PLATEGA_MERCHANT_ID` | Для Platega    | Идентификатор мерчанта.                                                                                 |
| `PLATEGA_SECRET`      | Для Platega    | Секрет провайдера. Без пары ключей клиент возвращает недоступность способа оплаты.                      |
| `TEST_DATABASE_URL`   | Для тестов     | Выделенная тестовая БД; приложение её не использует.                                                    |
| `TEST_REDIS_URL`      | Для тестов     | Выделенный Redis для интеграционных тестов очереди.                                                     |

Учётные данные PostgreSQL применяются контейнером при создании пустой БД. Изменение `.env` не меняет пароль уже существующего пользователя в томе `pgdata`.

## Адреса подключений

Пример для стандартного Compose, с заменой пароля в обоих местах:

```dotenv
POSTGRES_USER=db_user
POSTGRES_PASSWORD=CHANGE_ME
POSTGRES_DB=db_name
DATABASE_URL=postgres://db_user:CHANGE_ME@postgres:5432/db_name
REDIS_URL=redis://redis:6379
```

Для локального процесса и сервисов из инструкции разработки:

```dotenv
DATABASE_URL=postgres://postgres:dev_password@127.0.0.1:15432/bot_dev
REDIS_URL=redis://127.0.0.1:16379/0
```

В URL кодируйте специальные символы логина и пароля. Не используйте адрес `localhost` для обращения контейнера бота к соседнему контейнеру.

Адаптер Redis сохраняет имя пользователя, пароль и номер БД из URL; для `rediss:` включает TLS. Подключение использует IPv4. Дополнительных переменных для этих параметров нет. См. [redis.ts](../../src/infrastructure/queues/redis.ts).

## Что хранится в PostgreSQL

Через `/admin` изменяются настройки `global_settings`:

- `pkg_<имя>` — цены и состав пакета в формате `Stars_RUB_Сообщения_Фото`.
- `free_mode_enabled` — отключение списания текстовых сообщений.
- `policy_text`, `agreement_text`, `faq_text` — справочные тексты.
- `support_url`, `buy_stars_url` — ссылки поддержки и покупки Stars.
- `bonus_channel_id`, `bonus_channel_url` — проверяемый канал и ссылка на него.

Подробности редактирования и различия форматирования текстов: [администрирование](administration.md).

## Фотографии

Каталог `src/assets/free_pics/` читается относительно рабочей директории приложения. Поддерживаются обычные файлы `.jpg`, `.jpeg`, `.png`, `.webp`. Используйте материалы с подходящими правами.

Docker копирует каталог в образ. После добавления фотографий пересоберите бот; автоматического подключения каталога хоста через volume нет. В отсутствие файлов запрос локального фото завершится сообщением о недоступности, а резерв фото будет возвращён.
